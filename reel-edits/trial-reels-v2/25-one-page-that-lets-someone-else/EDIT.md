## Caption
Every service business has a method. In most, it lives in the founder's head.

The Delivery Playbook takes it out. One page per offer: the outcome in the client's words, the four to six stages every project moves through, what good looks like at each stage, where work is reviewed and by whom, and the three things that most often go off plan.

Write it with the person who'll use it. Run the next project from the page and fix what's missing.
